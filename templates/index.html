About HealthAI

HealthAI is an intelligent health assessment system built for the Veritas AI Hackathon (AI + Health track). It uses machine learning to analyze patient health data and predict the risk of common diseases.

Technology: Python, scikit-learn, Flask, Random Forest Classifier

Key Features:

  • Disease risk prediction (diabetes & heart disease)
  • Real-time health assessment
  • Patient risk stratification (Low/Medium/High)
  • Personalized health recommendations
  • Easy-to-use web interface
